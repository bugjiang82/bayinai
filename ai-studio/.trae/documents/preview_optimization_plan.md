# 图片编辑预览功能优化计划

## 1. 当前实现分析

### 1.1 现有预览功能结构
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **当前预览功能**:
  - 源图片预览（上传后）
  - 处理中进度条预览
  - 结果图片预览（编辑完成后）
  - 选区绘制预览（KonvaCanvas）

### 1.2 现有问题
1. **缺乏实时预览**: 用户在绘制选区时无法看到实际效果的预览
2. **API 返回后直接显示结果**: 没有渐变过渡效果
3. **缺少缩放和平移功能**: 无法仔细查看编辑细节
4. **预览窗口固定尺寸**: 无法适应不同大小的图片
5. **缺少对比功能**: 无法并排比较原图和编辑结果

## 2. 优化目标

### 2.1 功能增强
- 添加实时预览模式，在绘制选区时显示预期效果
- 添加缩放和平移功能，方便查看细节
- 添加原图/结果图对比功能
- 添加平滑的过渡动画效果
- 优化预览窗口的响应式布局

### 2.2 技术改进
- 优化图片加载性能
- 实现高效的图片缩放算法
- 改进用户交互体验

## 3. 具体优化计划

### 3.1 添加实时预览功能
- **文件**: `src/components/generate/KonvaCanvas.tsx`
- **任务**:
  - 在绘制选区时生成实时 mask 预览
  - 在图片上叠加半透明的效果预览层
  - 支持用户自定义预览强度

### 3.2 添加缩放和平移功能
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **任务**:
  - 添加缩放控制按钮（放大、缩小、适应屏幕）
  - 添加平移功能（拖拽移动图片）
  - 添加缩放级别指示器
  - 支持鼠标滚轮缩放

### 3.3 添加原图/结果图对比功能
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **任务**:
  - 添加对比模式开关
  - 使用滑块控制对比程度
  - 支持拖拽分割线进行左右对比

### 3.4 添加过渡动画效果
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **任务**:
  - 结果图片使用淡入动画显示
  - 处理状态使用平滑的进度条动画
  - 选区绘制使用实时反馈动画

### 3.5 优化预览窗口布局
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **任务**:
  - 预览窗口自适应图片尺寸
  - 添加全屏预览模式
  - 优化移动端预览体验

## 4. 技术实现细节

### 4.1 实时预览实现
- 使用 Canvas 叠加层显示预览效果
- 结合 mask 生成实时预览图
- 使用 requestAnimationFrame 优化预览更新

### 4.2 缩放平移实现
- 使用 CSS transform 实现缩放和平移
- 保存缩放状态到组件状态
- 支持多点触控缩放（移动端）

### 4.3 对比功能实现
- 使用 CSS clip-path 或绝对定位实现分割线
- 拖拽滑块改变分割线位置
- 左右两侧分别显示原图和结果图

## 5. 风险评估

### 5.1 潜在风险
- 实时预览可能影响性能
- Canvas 操作复杂可能导致卡顿
- 移动端兼容性可能存在问题

### 5.2 风险缓解措施
- 实现节流和防抖优化性能
- 添加性能检测，降级处理
- 进行跨浏览器和移动端测试

## 6. 实施步骤

1. **阶段 1**: 添加基础缩放和平移功能
2. **阶段 2**: 实现原图/结果图对比功能
3. **阶段 3**: 添加实时预览层
4. **阶段 4**: 优化过渡动画效果
5. **阶段 5**: 完善移动端适配
6. **阶段 6**: 测试和优化

## 7. 预期成果

- 用户可以缩放和平移查看图片细节
- 用户可以方便地对比原图和编辑结果
- 编辑结果有平滑的过渡动画
- 预览功能在各种设备上都能流畅运行

## 8. 测试计划

- 功能测试：验证所有预览功能正常工作
- 性能测试：测试大图片预览的流畅度
- 兼容性测试：确保在不同设备和浏览器中正常工作
