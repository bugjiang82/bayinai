# 图片编辑局部重绘功能优化计划

## 1. 当前实现分析

### 1.1 现有功能结构
- **文件**: `src/app/(main)/generate/edit/page.tsx`
- **核心功能**: 局部重绘 (inpaint) 模式
- **当前实现**: 
  - 使用 KonvaCanvas 进行选区绘制
  - 支持套索、笔刷、橡皮擦等工具
  - 通过 API 调用进行图像修复
  - 支持结构参考和风格参考图片

### 1.2 存在的问题
1. **Mask 生成问题**: 使用 mock maskImage，没有真正从 KonvaCanvas 生成 mask
2. **选区功能受限**: 选区工具功能相对基础
3. **用户体验**: 缺少实时预览和反馈
4. **API 调用**: 参数传递相对简单
5. **性能优化**: 大型选区可能导致性能问题

## 2. 优化目标

- 实现真正的 mask 生成从 KonvaCanvas 选区

- 优化 API 调用参数
- 提高性能和用户体验

### 2.2 技术改进

- 优化用户交互流程

## 4. 技术实现细节

### 4.1 Mask 生成实现
- 使用 Konva.js 的 `toDataURL()` 方法生成 mask
- 处理不同类型的选区（路径、矩形、圆形）
- 确保 mask 图像格式正确（黑白或透明背景）

### 4.2 性能优化策略
- 使用 requestAnimationFrame 优化 Canvas 渲染
- 实现选区的分层渲染
- 使用 Web Workers 处理复杂的选区计算

### 4.3 API 调用优化
- 添加超时处理
- 实现进度跟踪
- 优化图像数据传输
