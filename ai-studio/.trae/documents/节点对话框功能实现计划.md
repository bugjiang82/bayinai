# 节点对话框功能实现计划

## 需求概述

实现节点下方对话框的完整交互功能，包括：

1. @符号引用上级图片节点
2. 缩放按钮控制对话框高度
3. 大模型选择菜单
4. 图片比例及质量选择菜单

***

## 实现步骤

### 1. @符号引用图片节点功能

**目标**：用户输入@符号后，显示已连接的图片节点列表，用户点选后插入到输入框

**实现**：

* 修改 `BaseNode.tsx` 中的 `handlePromptChange` 方法，检测@符号

* 当检测到@符号时，设置 `showMentions` 状态显示菜单

* 菜单使用 `createPortal` 渲染到 `document.body`，z-index 设置为 2000

* 菜单内容使用**中文显示**（如"选择引用节点"、"引用节点"等）

* 点击节点后，将 `@节点名称` 插入到输入框

* 确保 API 调用时正确传递 `referencedParentIds` 参数

### 2. 缩放按钮功能

**目标**：点击按钮放大/缩小对话框，默认显示5行文字，放大后显示15行

**实现**：

* 确认 `isExpanded` 状态已存在

* 放大按钮无边框及背景色（已实现）

* 点击时切换 `isExpanded` 状态

* 对话框高度配置：

  * 默认（收起）：max-height: 200px（约5行）

  * 展开：max-height: 600px（约15行）

* textarea 高度随展开状态变化

### 3. 大模型选择菜单

**目标**：底部左侧显示模型选择，点击切换模型

**实现**：

* 使用 `group/model` hover 触发菜单显示

* 菜单使用 `absolute` 定位在按钮下方

* 支持的模型根据节点类型（image/video/text）过滤

* 选择后更新 `data.config.model`

* 确保 API 调用时使用正确的模型参数

### 4. 图片比例及质量选择菜单

**目标**：底部中间显示比例和质量选择

**实现**：

* 在 `ImageNode.tsx` 中的 `renderConfig` 已实现配置菜单

* 比例选项：1:1, 9:16, 16:9, 3:4, 4:3, 3:2, 2:3, 5:4, 4:5, 21:9, 自适应

* 质量选项：512P, 1K, 2K, 4K

* 使用 `createPortal` 渲染避免被父容器遮挡

* 选择后更新 `data.config.aspectRatio` 和 `data.config.quality`

* 确保 API 调用时正确传递参数

### 5. 修复已知问题

**问题**：弹出菜单可能被父容器遮挡

**解决方案**：

* 对话框容器使用 `overflow-visible`

* 弹出菜单使用 `createPortal` 渲染到 `document.body`

* 确保菜单 z-index 足够高（2000+）
