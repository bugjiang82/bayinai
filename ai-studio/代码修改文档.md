# AI Studio 代码修改文档

本文档记录了 AI Studio 项目中针对万相 2.7 模型及相关功能的代码修改，供其他 AI 开发工具参照。

## 一、万相 2.7 图生视频功能修复

### 1.1 问题描述

调用万相 2.7 模型进行图生视频时，报错：`"url error, please check url!"` (400 InvalidParameter)

### 1.2 问题原因

1. **API Endpoint 错误**：`wan2.7-i2v` 模型错误地使用了旧的 API 端点 `/services/aigc/image2video/video-synthesis`，而正确端点应该是 `/services/aigc/video-generation/video-synthesis`

2. **Media Type 错误**：使用了 `first_frame` 类型，而 wan2.7 应该使用 `reference_image`

3. **模型名称错误**：前端使用的模型名称是 `wan2.7-i2v`，但根据文档，正确的模型名称应该是 `wan2.7-r2v`

### 1.3 修改内容

#### 文件：`src/app/(main)/generate/video/page.tsx`

```typescript
// 修改前
{ value: "wan2.7-i2v", label: "万相 2.7", description: "高质量" }

// 修改后
{ value: "wan2.7-r2v", label: "万相 2.7", description: "高质量" }
```

#### 文件：`src/services/generation.service.ts`

**修改 1：新增 wan2.7 图生视频的端点判断**

```typescript
// 修改前
const isTextToVideoWan27 = isTextToVideo && isWan27;
const apiEndpoint = isTextToVideoWan27
  ? "/services/aigc/video-generation/video-synthesis"
  : "/services/aigc/image2video/video-synthesis";

// 修改后
const isWan27I2V = !isTextToVideo && isWan27;
const apiEndpoint = (isTextToVideoWan27 || isWan27I2V)
  ? "/services/aigc/video-generation/video-synthesis"
  : "/services/aigc/image2video/video-synthesis";
```

**修改 2：新增 URL 解析函数，支持本地文件转换为 base64**

```typescript
const resolveMediaUrl = async (input: string | undefined): Promise<string | undefined> => {
  if (!input) return undefined;
  if (input.startsWith("data:")) return input;
  if (input.startsWith("http://") || input.startsWith("https://") || input.startsWith("oss://")) return input;
  if (input.startsWith("/")) {
    const filePath = path.join(process.cwd(), "public", input);
    if (fs.existsSync(filePath)) {
      const buffer = fs.readFileSync(filePath);
      return `data:image/jpeg;base64,${buffer.toString("base64")}`;
    }
  }
  if (input.includes(",")) {
    return input;
  }
  return `data:image/jpeg;base64,${input}`;
};
```

**修改 3：使用 reference_image 类型**

```typescript
// 修改前
media: [
  { type: "first_frame", url: firstFrameData },
  ...(lastFrameData ? [{ type: "last_frame", url: lastFrameData }] : []),
],

// 修改后
media: [
  ...(firstFrameUrl ? [{ type: "reference_image", url: firstFrameUrl }] : []),
  ...(lastFrameUrl ? [{ type: "last_frame", url: lastFrameUrl }] : []),
],
```

### 1.4 参照要点

- **API 端点选择**：不同模型可能使用不同的 API 端点，需要根据模型文档确认
- **URL 处理**：DashScope 等 API 需要公网可访问的 URL 或 base64 数据，本地文件需要转换
- **Media Type**：不同版本的 API 可能使用不同的 type 字段值

## 三、视频生成后自动保存和封面生成

### 3.1 问题描述

用户生成的视频没有自动保存到本地，也不显示在作品页面。

### 3.2 问题原因

1. **视频未保存本地**：API 返回视频 URL 后，没有下载到本地
2. **无视频封面**：视频文件没有对应的缩略图
3. **未自动收藏**：视频生成后 `favorited` 为默认值 false，不显示在作品页面

### 3.3 修改内容

#### 文件：`src/services/generation.service.ts`

**修改 `updateVideoResult` 函数**

```typescript
export async function updateVideoResult(
  taskId: string,
  videoUrl: string,
  userId: string,
  cost?: number
): Promise<void> {
  // ... 查找生成记录 ...

  const outputDir = path.join(process.cwd(), "public", "outputs", userId);
  if (!fs.existsSync(outputDir)) {
    fs.mkdirSync(outputDir, { recursive: true });
  }

  let localVideoPath: string | null = null;
  let thumbnailPath: string | null = null;

  try {
    // 1. 下载视频到本地
    if (videoUrl && videoUrl.startsWith("http")) {
      const videoResponse = await fetch(videoUrl);
      if (videoResponse.ok) {
        const videoBuffer = Buffer.from(await videoResponse.arrayBuffer());
        const videoFilename = `${generation.id}.mp4`;
        const videoPath = path.join(outputDir, videoFilename);
        fs.writeFileSync(videoPath, videoBuffer);
        localVideoPath = `/outputs/${userId}/${videoFilename}`;

        // 2. 生成视频封面（使用 ffmpeg）
        try {
          const thumbnailFilename = `${generation.id}_thumb.jpg`;
          thumbnailPath = path.join(outputDir, thumbnailFilename);
          const ffmpegCommand = `ffmpeg -i "${videoPath}" -ss 00:00:01 -vframes 1 -vf "scale=256:256:force_original_aspect_ratio=decrease,pad=256:256:(ow-iw)/2:(oh-ih)/2" -y "${thumbnailPath}"`;
          const { execSync } = require("child_process");
          execSync(ffmpegCommand, { stdio: "pipe" });
        } catch (thumbError) {
          console.error("Failed to generate video thumbnail:", thumbError);
          thumbnailPath = null;
        }
      }
    }
  } catch (downloadError) {
    console.error("Failed to download video:", downloadError);
  }

  // 3. 更新数据库，设置本地路径和封面，并自动收藏
  await prisma.generation.update({
    where: { id: generation.id },
    data: {
      status: "COMPLETED",
      outputUrl: localVideoPath || videoUrl,
      thumbnailUrl: thumbnailPath ? `/outputs/${userId}/${path.basename(thumbnailPath)}` : null,
      favorited: true,  // 自动收藏
    },
  });

  // 4. 扣减积分（如有）
  if (cost && cost > 0) {
    await deductCredits({ ... });
  }
}
```

### 3.4 参照要点

- **异步文件下载**：使用 fetch 下载远程文件，然后用 fs 写入本地
- **ffmpeg 集成**：使用 ffmpeg 从视频提取帧生成缩略图
- **自动收藏**：设置 `favorited: true` 使生成的内容自动显示在作品页面
- **错误处理**：下载和封面生成都做了错误处理，不影响主流程

## 四、历史记录显示优化

### 4.1 问题描述

用户打开图像生成页面时，浏览器控制台显示传输了几十 MB 的数据，加载缓慢。

### 4.2 问题原因

1. **API 返回了完整的 `params` 字段**：可能包含 base64 编码的参考图片
2. **返回了 `inputUrl` 字段**：图生图的参考图片 URL 可能很大
3. **缩略图不存在时使用完整图片**：fallback 到 outputUrl（2K/4K 图片）

### 4.3 修改内容

#### 文件：`src/services/generation.service.ts`

**优化 `getHistory` 函数**

```typescript
// 修改前：直接返回 item.params, item.inputUrl, item.outputUrl

// 修改后：在服务端解析 params，只返回必要字段
return {
  list: list.map((item) => {
    let parsedParams: Record<string, any> = {};
    if (item.params) {
      try {
        parsedParams = typeof item.params === 'string' ? JSON.parse(item.params) : item.params;
      } catch {}
    }
    return {
      id: item.id,
      type: item.type,
      status: item.status,
      prompt: item.prompt,
      outputUrl: item.outputUrl,
      thumbnailUrl: item.thumbnailUrl,
      width: item.width,
      height: item.height,
      cost: item.cost,
      // 解析 params 并提取必要字段，不再返回原始 params
      model: parsedParams.model || "flash",
      imageSize: parsedParams.imageSize || "1K",
      aspectRatio: parsedParams.aspectRatio || "",
      createdAt: item.createdAt.toISOString(),
      completedAt: item.completedAt?.toISOString(),
      favorited: (item as any).favorited ?? false,
      favoritedAt: (item as any).favoritedAt?.toISOString() ?? null,
    };
  }),
};
```

### 4.4 参照要点

- **服务端解析**：将 JSON 解析从客户端移到服务端，减少网络传输
- **字段裁剪**：只返回列表展示必要的字段，完整数据通过单独 API 获取
- **缩略图优先**：前端只加载缩略图，避免加载完整分辨率图片
- **优雅降级**：无缩略图时显示占位图，不显示空白

## 五、部署注意事项

### 5.1 环境要求

- **Node.js**: >= 18.x
- **ffmpeg**: 必须安装（用于视频封面生成）

```bash
sudo apt update && sudo apt install -y ffmpeg
```

### 5.2 PM2 部署

```bash
# 构建
npm run build

# 启动
pm2 start npm --name "ai-studio" -- start

# 查看日志
pm2 logs ai-studio

# 重启
pm2 restart ai-studio
```

### 5.3 Nginx 配置

项目使用 Nginx 反向代理，端口配置：
- Next.js 监听：3000
- Nginx 监听：5050
